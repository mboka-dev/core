Démonstrations Téléphone

Téléphone

Analyse et formatage des numéros +242.

Voir le source

Exemple fictif, avec ou sans +242.

Format international

Format national
Résultat complet de parse

Utilisation

Appelez la fonction depuis votre application JavaScript ou Python.

import { phone } from '@mboka-dev/core';
const numero = phone.parse('06 123 45 67');
from mboka import phone
numero = phone.parse("06 123 45 67")

Limites

Le plan de numérotation est provisoire. Un format reconnu ne vérifie ni l’existence du numéro ni son attribution.

Le numéro saisi reste sur cette page. Aucun envoi, aucun traceur.

Démonstrations Montants

Montants

Des montants en FCFA, prêts à afficher.

Voir le source

Exemple fictif : 125000. Saisissez un entier sans séparateur.

Montant formaté

Utilisation

Choisissez le libellé qui convient à votre interface.

import { money } from '@mboka-dev/core';
money.format(125000);
from mboka import money
money.format(125000)

Limites

Cette fonction formate un entier : elle ne convertit pas les devises et ne lit pas un montant déjà écrit. Les décimales et les entiers dépassant la précision de JavaScript sont refusés.

Le montant saisi reste dans votre navigateur.

    Démarrer Installation

    Installation

    Une même bibliothèque, deux écosystèmes.

    JavaScript / TypeScript

    Avec Node.js 22 ou une version ultérieure :

    Terminal 
    npm install @mboka-dev/core

    Les types TypeScript sont inclus. Les démos fonctionnent aussi dans un navigateur grâce à un module ES chargé depuis un CDN.

    Python

    Avec Python 3.10 ou une version ultérieure, dans votre environnement virtuel :

    Terminal 
    pip install mboka

    Les onglets Python présentent du code à exécuter dans votre application ; le site exécute uniquement le paquet JavaScript.

    À vous de jouer.

    Ouvrez une démonstration, essayez une entrée et copiez l’exemple dans votre projet. Pour les détails de l’API, consultez les exemples du dépôt.
